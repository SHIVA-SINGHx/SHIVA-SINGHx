# 💫 About Me:
I’m a Software Engineer with a strong background in full-stack development and a growing focus on **backend engineering, cloud infrastructure, and DevOps**.

I build backend applications and APIs using **Node.js, Python, and Go**, and have hands-on experience with **React, Express, Django, FastAPI, and PostgreSQL**.

My primary interest lies in **cloud and infrastructure engineering**. I work with **AWS and Azure**, containerize applications with **Docker**, and use **Kubernetes** to understand and manage containerized workloads. I also work with **Terraform and Ansible** for infrastructure and configuration automation, and build CI/CD pipelines using **Jenkins and GitHub Actions**.

I’m particularly interested in **microservices, distributed systems, scalable backend architecture, cloud-native applications, and deployment automation** — especially understanding what happens behind the scenes when software moves from code to production.

I’m also exploring **Generative AI**, building practical applications and experimenting with how AI can be integrated into real-world software systems.

I learn by building, breaking, debugging, and rebuilding things — while contributing to open source and sharing what I learn along the way.
